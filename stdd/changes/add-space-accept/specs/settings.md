# 规格增量：settings

## 新增

### 需求：空格接受建议开关

#### 场景 [settings.09] 空格接受建议默认开启

- GIVEN 从没修改过设置
- WHEN 读取设置
- THEN 空格接受建议 SHALL 是开启

#### 场景 [settings.10] 空格接受建议修改后持久保存

- GIVEN 用户关闭了空格接受建议
- WHEN 输入法重启后读取设置
- THEN 空格接受建议 SHALL 是关闭

#### 场景 [settings.11] 设置窗里能切换空格接受建议

- WHEN 用户打开设置窗
- THEN 设置窗 SHALL 有「空格接受建议」开关，切换后下一次按键生效
- 验证：手动——界面需要真机操作
